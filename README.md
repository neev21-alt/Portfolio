# Neev Savla — Portfolio

> Personal portfolio website of **Neev Savla** — Cyber Security Engineering student at SAKEC Mumbai.  
> Frontend & Java Developer · Open to internships.

🔗 **Live:** https://neev21-alt.github.io/Portfolio/

---

## ✨ Features

- **Premium dark UI** — deep navy/indigo theme with violet gradient accents
- **Custom cursor** — dot + lagging ring that reacts to hover
- **3D card tilt** — every card tilts in 3D on mouse movement
- **Animated gradient blobs** — ambient background lighting effect
- **Infinite skills marquee** — auto-scrolling tech strip
- **Scroll-driven reveals** — sections animate in as you scroll
- **Counter animation** — stats count up on scroll into view
- **Hero text cycle** — rotating subtitle every 5 seconds
- **Scroll progress bar** — indigo gradient line at the top
- **Hamburger menu** — fully accessible mobile navigation
- **Resume page** — view & print-to-PDF resume at `/resume.html`
- **Fully responsive** — tested at 400px, 768px, 1440px

---

## 🛠️ Tech Stack

| Layer | Tech |
|---|---|
| Structure | HTML5 (semantic) |
| Styling | Vanilla CSS3 (custom properties, grid, flexbox, animations) |
| Logic | Vanilla JavaScript (no frameworks, no dependencies) |
| Fonts | Plus Jakarta Sans · JetBrains Mono (Google Fonts) |
| Icons | Font Awesome 6 (resume page only) |
| Hosting | GitHub Pages |
